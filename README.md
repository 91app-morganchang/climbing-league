# 攀岩社季度排位賽 排行榜

純靜態網頁：Google Sheet 存資料，瀏覽器讀 CSV 後用 `scoring.js` 計算排名。

## 本機預覽 / 測試
```
node serve.js        # http://localhost:5173
node --test test/scoring.test.js
```

## Google Sheet 欄位（表頭名稱需完全一致）
| 分頁 | 欄位 |
|---|---|
| 成績 | 活動日期, 選手, 認定等級, Slack貼文時間(選填), Slack連結(選填), 備註 |
| 選手 | 姓名, 部門, 首次參加日, 隊名 |
| 隊伍 | 隊名, 成員1, 成員2(單人留空) |
| 設定 | 項目, 值（列：結算截止日期、新人起算日） |

日期格式請用 `2026-10-10`；時間 `2026-10-12 09:30`。等級填 `V0`~`V12`。

## 接上 Google Sheet
分享設定改為「知道連結的人可檢視」即可（不需發布到網路）。在 config.js 填 SHEET_ID 和各分頁 gid（分頁網址最後的 gid=數字）。
成績頁的「幹部認定等級」「Slack貼文時間(選填)」欄名也可使用；設定頁不需表頭，每列「項目,值」。其餘公式欄位網頁會忽略。

## 規則對照
- V0=0.5 分、V1=1 分…；同人同日取最高；活動日後下週一 12:00 前貼文才算（有填貼文時間才檢查）
- 隊伍積分 = 「選手」頁中隊名相同者的積分總和（換夥伴後離隊者積分保留）
- 最強新人 = 首次參加日 ≥ 新人起算日者，每個月各選一位冠軍（當月積分最高且 > 0，同分並列）
- 改結算截止日期（設定頁）即可提前結算
